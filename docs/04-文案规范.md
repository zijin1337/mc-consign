# 文案规范

2026-09-05 全站文案打磨时定稿。改任何面向用户的文字前先读这份；新增页面、通知、错误提示都按这里的写法。

站点定位：面向国内 Minecraft / Hypixel 玩家的正版账号寄售信息平台。平台只做信息展示与人工中介撮合，不经手资金、不托管账号。视觉语言是近黑底、荧光绿、零圆角、等宽小标签的 block-market 风格，用户对「格调」要求很高：文案要**平实、确定、简短、可信**，像一份写得很好的产品说明，不像营销页。

## 1. 语气

- 用「你」，不用「您」（法律条款正文除外；条款页的说明性文字也用「你」）。
- 陈述句，不用感叹号，不用「哦 / 啦 / 呢 / 哟」，不用表情符号。
- 不用营销词：立即、马上、火爆、超值、抢购、海量、极速、强力、专业团队、放心、安心、贴心。
- 不夸大、不承诺结果：不写「100% 安全」「保证」；写清规则和边界即可。
- 说人话：能用日常词就不用行话；必须用术语时全站同一个词。
- 一句话说一件事。描述性文字最多两句；第一句说「这是什么」，第二句说「你能做什么 / 规则是什么」。

## 2. 术语（全站只用左边这个）

| 用 | 不用 |
|---|---|
| 账号 | 号、帐号、商品（面向用户的文案里不叫商品；后台管理页可保留「商品管理」这个既有页名） |
| 意向单 | 意向、订单、单子（可在口语化上下文写「这张意向单」） |
| 中介 | 客服、担保人、经纪人 |
| 中介费 | 服务费、手续费 |
| 信用分 | 积分、信誉 |
| 求购 / 求购单 | 需求、求购信息 |
| 推荐（把账号推荐给求购买家） | 报价、响应、投递 |
| 置顶 | 推广、加精 |
| 审核 / 审核通过 / 审核未通过 | 上架审批、拒绝（「已拒绝」作为状态名保留） |
| 下架 / 重新上架 | 隐藏、撤下 |
| 成交 / 已成交 | 完成交易（动作按钮「完成交易」保留） |
| 正版 ID | 游戏名、用户名（指游戏内名称时） |
| 会员类型（VIP / MVP+…） | 等级（等级专指 Hypixel 等级） |
| QQ 邮箱 | 邮件、邮箱（指验证码 / 通知去向时写清「QQ 邮箱」） |
| 网站 / 平台：面向用户说「网站」，说规则与立场时说「平台」 | 系统、本站、我们 |

## 3. 固定句（同一件事全站同一句，别再造新说法）

- 资金立场：**「网站不收款，付款只在中介确认后进行。」** 短版：**「网站不收款。」**
- 防诈：**「任何人索要你的账号密码或邮箱验证码，或让你付款到中介以外的账户，都是诈骗。」**
- 中介联系：**「中介会通过 QQ 联系你。」**
- 打码：**「用户名已打码，交易时由中介核对身份。」**
- 官方数据：**「Hypixel 官方数据每 6 小时更新，只反映公开统计，不代表账号所有权或可交易性。」**
- 免责（页脚）：**「本站仅提供账号信息展示与中介撮合服务，不经手资金。非 Microsoft 或 Mojang 官方平台，不代表其认可或授权。Minecraft 为其权利人商标。」**

## 4. 各类文案的写法

- **页面标题**：名词短语，2～6 字：账号市场、成交记录、求购大厅、我的意向单、中介台、审核队列。
- **页面描述**：一到两句，说清这页是什么、规则是什么。不要在描述里重复标题。
- **按钮**：动词开头，2～4 字，说清结果：发布账号、提交审核、我要买、去下单、推荐给买家、关闭求购、下架、恢复。危险操作用动词本身（删除、封禁），不写「确认」；确认弹窗才写后果。
- **确认弹窗**：先说后果，再问：「下架会关闭 3 张排队中的意向单并通知买家。确定下架？」
- **空状态**：统一「还没有 X」（用户自己的东西）/「没有符合条件的 X」（筛选结果）/「暂无 X」（系统数据），后面可跟一个动作按钮。不写「空空如也」这类修辞。
- **成功提示**：说已经发生的事和接下来会发生的事：「账号已提交，等待审核。结果会通知你。」
- **错误提示**：说原因和怎么办：「预算下限不能高于上限。」「验证码已过期，请重新获取。」不写「出错了」「操作失败」。
- **表单标签**：名词；提示（hint）说格式或用途，不重复标签：「Hypixel 等级」提示「以游戏内显示为准」。必填用星号，不写「（必填）」。
- **通知标题**：8 字内、主谓结构、无标点：账号审核通过 / 买家已排队 / 交易完成 / 求购收到推荐。正文一到两句，第一句说发生了什么（带账号名或单号），第二句说你要做什么。
- **邮件**：与站内通知同文，末尾一行「查看：链接」。
- **状态名**：两到三字：待审核、在售、交易中、已成交、已下架；待分派、待联系、交易中、已完成、已取消；求购中、已完成、已关闭、已下架、已过期。
- **数字与单位**：数字与单位之间空一格（30 天、¥4,800、120 级）；中英文之间空一格（Hypixel 等级、QQ 邮箱）；全角标点；范围用「～」；序号用 01 / 02。
- **英文微标签**（eyebrow / cover 角标）：保持现有词表，不新增。

## 5. 保护字串（e2e 断言依赖，改了会红）

`scripts/e2e.ts` 按文案断言了一批按钮、提示与状态名。

改任何面向用户的字串前，先在 `scripts/e2e.ts` 里 `grep -F` 一下；命中的要么保持原样，要么同一次提交里把 e2e 一起改。 常见受保护的：按钮「提交审核」「登录」「注册」「发送验证码」「我要买」「发布求购」「推荐给买家」「去下单」「谢绝」「关闭求购」「下架」「恢复」「查询」「去推荐」「处理」「完成交易」「开始交易」「置顶」「取消置顶」「延长」「解除封禁并移出黑名单」；提示「验证码已发送到」「封面」「已填入」「违禁词」「求购已发布」「已推荐给买家」「本单来自你的求购」「来自求购」「已通过意向单」「修改已保存」「你已在排队」；状态与词「待审核」「在售」「已完成」「已关闭」「已下架」「已过期」「买家已下单」「待分派」「会员不限」「指定你」；页面文字「HYPIXEL / 官方数据」「置顶推荐」「其中 1 个置顶」「找到 N 条求购」「登录后发布」「验证码已发送到」等。
